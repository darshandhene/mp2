# Sources

Sources consulted while building this MP. The course `README.md` is the assignment and is unchanged.

- CS 409 MP2 assignment, course template repository `cs409-fa25/mp2`, including the GitHub Actions workflow in `.github/workflows/deploy.yml`.
- [TheMealDB API](https://www.themealdb.com/api.php). This app uses the free test key `1` in the public V1 URL. No paid endpoints are used.
- [React](https://react.dev/learn) and [TypeScript with React](https://www.typescriptlang.org/docs/handbook/react.html).
- [React Router](https://reactrouter.com/start/declarative/installation). The app uses `BrowserRouter`, `Link`, and `NavLink` as the assignment specifies. The installed package is `react-router-dom`.
- [Axios](https://axios-http.com/docs/intro).
- [Vite static deployment](https://vite.dev/guide/static-deploy.html), including the repository `base` of `/mp2/`.
- [CSS Modules](https://vite.dev/guide/features.html#css-modules) and [Normalize.css](https://necolas.github.io/normalize.css/).
- [MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development) for HTML, CSS, and accessibility practices such as labels, `aria-pressed`, and visible focus.
- [Manrope](https://fonts.google.com/specimen/Manrope) from Google Fonts, licensed under the SIL Open Font License.
- [Vitest](https://vitest.dev/guide/), [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/), and [user-event](https://testing-library.com/docs/user-event/intro) for automated tests.
- LLM assistance: Cursor and its agents generated application and redesign code; Codex assisted with planning, review, verification, and deployment. Actual conversation exports are included in [llm_chatlogs](llm_chatlogs/README.md). See the export index for provenance and completeness limits, and answer the grading form’s LLM survey questions.
